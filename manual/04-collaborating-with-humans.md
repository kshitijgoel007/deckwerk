# Collaborating with humans

Click **Collaborate**. DeckWerk starts a live editing session, opens the shared presentation, and copies an invite link to your clipboard.

Send that link to your collaborators. They open it in a browser, enter their name, and edit the same presentation with you. Everyone sees each other's slide, cursor, selection, and edits as they happen.

> Screenshot placeholder: Two people editing the same slide with visible presence.

Use comments when an edit needs discussion. Right-click an object and choose **Add comment…**, or use the comment bubble on a slide.

Anyone in the session can **Download** the current presentation or **Present** it. The host can copy the invite again with **Copy Invite Link**.

Click **End collaboration** to save the work, close the session for everyone, and return to the desktop editor.

Only share collaboration links over a network you trust.
