# Product ideas

Notes collected while exercising real imported decks and building the editor.

- Add an import-QA view that overlays the Keynote/PDF reference and imported
  slide with an opacity scrubber, plus numeric geometry diffs per element.
- Give semantic text roles an audit mode: tint title, heading, body and caption
  boxes, flag unassigned imported text, and approve role detection in bulk.
- Add a deck asset library with usage counts, deduplication, relinking and a
  safe “remove unused assets” action.
- Add reusable symbols/components for recurring logos, footers, citations and
  diagram nodes, with deck-wide editing.
- Extend Morph with a manual match inspector when content heuristics find
  several plausible counterparts.
- Add animation rehearsal controls: scrub build steps, preview one transition,
  and display click groups directly on the canvas.
- Add connector attachment points and optional constraints while preserving
  free endpoints for imported diagram arrows.
- Add a PDF page picker on drop; the current vector-backed drop shows page one.
- Add deck-level LaTeX macros and an equation source popover with live error
  feedback for formulas too large to edit comfortably in place.
- Add accessibility checks for contrast, minimum text size, missing image alt
  text and reading order.
- Add presenter view with notes, timer, next-slide preview and build progress.
- Add a theme-change preview/diff that states exactly which properties and
  inline overrides will change before committing the operation.
