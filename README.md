# Slide Editor

An HTML presentation tool built around **video as a first-class object**, for
research talks that are mostly moving pictures.

- Slides are HTML and present as HTML.
- Positions are set by dragging; typography and colour are set as CSS.
- Video: drag a file in and it plays. Trim and crop without leaving the app.
- Keynote `.key` import that needs neither Keynote nor PowerPoint installed.
- Runs identically on macOS and Linux.

## Quick start

```bash
npm install
npm run setup:importer
npm run dev
```

To open a deck straight away:

```bash
npm run dev -- examples/demo-deck
```

## How a deck is stored

A deck is a **folder**, not a file:

```
my-talk/
  deck.json     content, geometry and build steps
  theme.css     fonts, sizes, colours — hand-edited, never rewritten by the app
  assets/       images and video, referenced not embedded
```

`deck.json` is plain JSON validated against a schema
([src/shared/deck.ts](src/shared/deck.ts)), so it diffs cleanly in git and can
be generated by a script. Media stays as real files, which is what makes a
200 MB clip practical.

## The split: drag vs. code

Anything **spatial** is done by direct manipulation — drag, 8-handle resize,
alignment snapping, arrow-key nudge, multi-select, z-order.

Anything **typographic** is done in `theme.css`, edited in the app's CodeMirror
panel with live reload. Elements carry CSS classes; the stylesheet does the rest.

```css
.title { font-size: 104px; font-weight: 700; letter-spacing: -0.03em; }
```

There is also a `type: "html"` element for anything the editor doesn't model —
it still drags and resizes like everything else.

## Video

- **Drop** a video onto a slide: it is copied into `assets/` under a
  content-hashed name (so re-dropping the same file doesn't duplicate it),
  probed with `ffprobe`, and placed at its natural aspect ratio.
- **Defaults are autoplay + loop + muted.** Muting is not cosmetic — Chromium
  refuses unmuted autoplay without a user gesture, so an unmuted autoplaying
  video would silently never start.
- **Trim & Crop** (double-click a video, or the button in the inspector) opens a
  separate window: scrub bar with in/out handles, a crop rectangle dragged over
  the frame, and the exact `ffmpeg` command shown before you run it. It writes a
  **new** file and relinks the element; the original is never modified.
- `ffmpeg`/`ffprobe` binaries are bundled per platform, so nothing to install.

## Builds and animation

Each slide has a timeline of `trigger → action` entries:

```json
{ "trigger": { "on": "click" },   "action": { "type": "appear", "target": "e2" } }
{ "trigger": { "on": "afterPrev", "delay": 300 }, "action": { "type": "play", "target": "e2" } }
{ "trigger": { "on": "mediaEnd", "ref": "e2" },   "action": { "type": "appear", "target": "e3" } }
```

Triggers: `click`, `afterPrev`, `withPrev`, `mediaEnd`. Actions: `appear`,
`disappear`, `play`, `pause`, `seek`, `addClass`, `removeClass`. The UI currently
authors reveal-on-click; the rest is schema-supported and needs no format change
to light up. `addClass` is the hook that makes future animations a CSS problem
rather than a code problem.

Slides with no timeline show everything at once — the common case needs no
authoring.

## Keynote import

Click **Import Keynote…**, or run the importer directly:

```bash
./.venv-import/bin/python importers/keynote/import_keynote.py talk.key --out ./talk-deck
```

A `--report` flag analyses coverage without writing anything.

**No Apple or Microsoft software is involved.** A `.key` file is a package of
`.iwa` streams — Snappy-framed protobuf. The importer decodes them with
[`keynote-parser`](https://pypi.org/project/keynote-parser/) and walks the object
graph itself. It ships as a PyInstaller binary, so end users need no Python
either, and the whole path works on Linux.

What comes across: slide order and canvas size, text content, images, video
(with start/end points), vector shapes and connector arrows with their real
stroke colours, groups (flattened), and speaker notes.

Imported text keeps its layout-critical face, size, colour or gradient, and
alignment; it also carries a `.kn-text` class so those inline values can be
removed and replaced in `theme.css`. Keynote's build graph is not imported —
guessing it wrong is worse than leaving slides fully visible.

**Import degrades, it never fails.** Anything unrecognised becomes a visible
`unsupported` placeholder that keeps its original geometry, so the slide still
lays out and the gap is obvious rather than silent.

Measured over 24 real lecture decks (~1,550 slides, ~16,000 elements): every deck
imported, with roughly 0.2% of objects falling back to placeholders — only tables
and charts, which are not modelled yet.

## Presenting

**Present** opens fullscreen on an external display when one is attached, running
the *same* player as the editor preview, so what you rehearse is what the
projector shows.

Arrows / space / click advance, `B` blanks, `Esc` exits.

## Export

**Export web…** writes a self-contained folder — `index.html`, `player.js`,
`theme.css`, `assets/` — that opens in any browser with no app installed. This
is the safest way to present on a machine you don't control. The deck is inlined
into the HTML so it works straight off `file://`.

## Testing

```bash
npm test
```

The ffmpeg tests run against real binaries and assert on actual output duration
and pixel dimensions. To run the Keynote import regression suite, point it at a
folder of real decks:

```bash
KEYNOTE_FIXTURES=/path/to/decks npm test
```

## Building

```bash
npm run dist          # current platform
npm run dist:linux    # AppImage + deb
```

`npm run build:importer` freezes the Keynote importer into a standalone binary
(verified to run with an empty environment — no Python on PATH).

## Layout

```
src/main/        Electron main: files, ffmpeg, windows, importer subprocess
src/preload/     the renderer's entire view of the outside world
src/renderer/
  player/        deck.json -> DOM + timeline runtime (shared by all three surfaces)
  editor/        canvas, inspector, slide rail, build panel, CSS editor
  trim/          video trim & crop window
  export/        entry point for the standalone bundle
src/shared/      deck schema, timeline logic, geometry, IPC contract
importers/       Keynote .key importer (Python sidecar)
```

## Known gaps

- Tables and charts import as placeholders.
- Image masks (Keynote's crop) are approximated by stretching to the displayed box.
- Rotated groups are flattened without composing child rotation.
- Multi-select resize moves elements but does not scale them as a group.
- Slide backgrounds import as white; Keynote's slide fill is not read yet.
